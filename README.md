# JN-Quake
a web to track real-time earthquake detections in Japan

## current features
*   interactive map (using leaflet.js)
*   epic neon UIs (work in progress)
*   live data polling (updates every 15 seconds for now, but will update in the future)

## built with?
*   **Frontend:** HTML5, CSS3, Vanilla JavaScript
*   **Mapping:** [Leaflet.js](https://leafletjs.com/)
*   **Map Tiles:** Esri World Dark Gray Canvas
*   **API Data:** [Wolfx API](https://wolfx.jp/) (JMA Earthquake Data)
